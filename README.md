# 📇 Contact Manager Web Application

یک اپلیکیشن مدیریت مخاطبین (Contact Manager) ساخته شده با React که امکان ایجاد، مشاهده، ویرایش و حذف مخاطبین را فراهم می‌کند.

![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)
![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)

## ✨ ویژگی‌های اصلی

- ✅ **ایجاد مخاطب جدید** - افزودن مخاطب با اطلاعات کامل
- 👁️ **مشاهده جزئیات مخاطب** - نمایش کامل اطلاعات هر مخاطب
- ✏️ **ویرایش مخاطب** - به‌روزرسانی اطلاعات مخاطبین
- 🗑️ **حذف مخاطب** - حذف مخاطب با تأیید کاربر
- 🔍 **جستجوی مخاطبین** - یافتن سریع مخاطب مورد نظر
- 📱 **واکنش‌گرا (Responsive)** - طراحی سازگار با همه دستگاه‌ها

## 🚀 تکنولوژی‌های استفاده شده

- **React** - کتابخانه اصلی فرانت‌اند
- **React Hooks** - useState, useEffect و سایر هوک‌ها
- **JSON db** - ذخیره‌سازی داده‌ها در جیسون
- **CSS Modules / Styled Components** - برای استایل‌دهی
- **React Router** (اختیاری) - برای مسیریابی بین صفحات
- **React Icons** (اختیاری) - برای آیکون‌های زیبا
